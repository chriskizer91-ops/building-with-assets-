Walking Paths

Map any painting: where feet can go, what they pass behind, the ways out

Start with a picture of a map

A painting, a drawing, a photo of one: any picture. Then mark where people can walk on it.

You can also drop pictures here, or paste one (Ctrl+V).

Drop pictures to add them as maps, or a maps file to open it

Draw and change

Draw shapes

Tap the ground in the picture: the wand finds the patch of the same colour round it and outlines it. Too little? Spread it further. Too much? Less. Tap again to add more ground.

    Save and share

    The maps file has every map with its picture inside. Open it here again to carry on, or give it to Claude to put the maps in a game.

    The walk-around page is one file you can open anywhere, or add to Mooncart, to walk round these maps.

    Picture size

    The map keeps its size, so everything drawn on it stays where it is. A smaller picture just has fewer pixels to stretch over it, so it gets softer the closer the camera comes.
